# Validator challenge data

Copies of the two day 1 datasets with problems planted in them. Your job is to build a Claude Code skill that finds them. The answer key is with your instructor.

- `airway-altered/`: counts.tsv.gz, samples.csv and a draft methods.txt
- `moving-pictures-altered/`: counts.tsv, taxonomy.tsv, samples.tsv and a draft methods.txt

Rules: your validator must work on the files alone. Do not compare them with the original day 1 files. Run it on the original files too: a good validator passes clean data without false alarms.
